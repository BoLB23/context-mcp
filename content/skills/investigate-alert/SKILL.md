# Investigate an alert

Starter skill: replace this procedure with your team’s investigation workflow.

1. Identify the environment and resolve unfamiliar terms using company context.
2. Read the relevant request path and telemetry location documents.
3. Use available telemetry tools to collect current evidence. If those tools or
   access are unavailable, report what is missing.
4. Separate observed evidence from hypotheses and cite the sources consulted.
